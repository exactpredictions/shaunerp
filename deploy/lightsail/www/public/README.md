# Shaun Infomedia — Light Corporate Website

A new multi-page, light corporate site using the approved navy/orange logo.

## Pages
- index.html — corporate home
- products.html — four product families
- services.html — Custom ERP, analytics, APIs, modernization
- about.html — company profile
- founder.html — founder vision and expertise
- contact.html — contact + frontend enquiry form
- privacy.html
- terms.html

## Deploy
Upload the CONTENTS of this folder to the document root for https://shauninfomedia.com/

No Node, build step, PHP, database, external fonts, or CDN required.

## Important before production
1. Connect the contact form to a real backend or mail service.
2. Confirm public links for Only41 and ShaunERP when ready.
3. Review the starter Privacy and Terms pages.
4. If desired, add a professional founder photograph to founder.html.
5. Keep the approved logo files in assets/img/.

## Design direction
Light enterprise/SaaS corporate style: white background, navy typography, restrained blue surfaces and orange calls-to-action.
